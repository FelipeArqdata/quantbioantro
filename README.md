# quantbioantro

Projeto sobre métodos quantitativos, estrutura dos dados e inferência na bioarqueologia brasileira.

## Ideia central

O projeto investiga a relação:

**estrutura dos dados → modelo probabilístico → qualidade da inferência → consequência para a interpretação bioantropológica**

O objetivo não é apenas contabilizar quais testes estatísticos são utilizados, mas investigar como as características dos dados e os objetivos científicos se relacionam às escolhas analíticas.

## Trabalho A — Mapeamento das práticas quantitativas

Pergunta provisória:

> Como a estrutura dos dados, os objetivos inferenciais e os métodos estatísticos se relacionam na bioarqueologia brasileira contemporânea?

Pretende-se mapear, entre outros aspectos:

- tipo de pergunta científica;
- unidade de análise;
- tipo de outcome;
- estrutura hierárquica;
- tamanho amostral;
- pooling;
- missing data;
- incerteza;
- testes de normalidade;
- NHST;
- effect sizes e intervalos;
- modelos estatísticos utilizados;
- model diagnostics.

## Trabalho B — Benchmark por simulação

Pergunta provisória:

> Em condições típicas dos dados bioarqueológicos, como diferentes estratégias analíticas se comportam em termos de viés, incerteza, calibração e robustez inferencial?

A proposta é utilizar propriedades observadas em dados bioarqueológicos reais para construir simulações nas quais os parâmetros verdadeiros são conhecidos.

Possíveis métricas:

- bias;
- RMSE;
- interval coverage;
- Type I error;
- power;
- Type M error;
- Type S / false-sign error;
- calibração;
- estabilidade das estimativas.

## Hipótese conceitual

Os modelos estatísticos fazem parte da ponte inferencial entre os vestígios bioarqueológicos e as interpretações sobre processos biológicos, sociais e culturais no passado ou presente

Assim, uma especificação inadequada do modelo pode afetar não apenas estimativas numéricas, mas também o peso evidencial atribuído a interpretações bioantropológicas.
